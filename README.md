# NTSL Automotive — Website

A React + Vite website foundation for NTSL Automotive Pvt. Ltd., prepared as a demonstration for the Biratnagar, Nepal branch.

## Stack
- React
- Vite
- Lucide icons
- Custom responsive CSS

## Development
`npm install`  
`npm run dev`

## Production build
`npm run build`

## Preview deployment
The `build/ntsl-foundation` branch is linked to Vercel for preview deployments. The production branch remains `main`.

## Important project rules
- Do not invent company history, branch details, contact information, tractor models, specifications, prices, warranties, testimonials or service promises.
- Use only official or company-approved Powertrac and NTSL photographs. Do not use unrelated people or other dealerships' photos.
- The enquiry form is currently a front-end demonstration. It does not transmit or store personal information.
- Privacy and terms pages are drafts and require company/legal review before launch.
- Never commit credentials, customer data, private company documents or API secrets.

## Security
The static hosting headers in `public/_headers` provide baseline browser security headers. Review the Content Security Policy whenever external services or assets are introduced. A production enquiry backend will require server-side validation, spam/rate limiting, access controls, secure storage, retention rules and monitoring.

## Status
Initial frontend foundation. Not production-ready until company facts, approved assets, live enquiry handling, accessibility, security and legal review are completed.
